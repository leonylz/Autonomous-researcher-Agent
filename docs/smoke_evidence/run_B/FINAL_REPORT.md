## 1. Summary（摘要）

本实验验证了 **Baseline MLP [64, 32]** 在合成 4 高斯簇分类任务上的基线性能。实验在固定 seed 的合成 2D 高斯簇数据（4 簇，训练/测试各 2000 样本）上，使用 CPU 训练 MLP（隐藏层 [64, 32]），AdamW 优化器，lr=1e-3，batch_size=128，训练 10 epochs。

**最终结果：test_acc = 0.9980，远超 0.90 目标，任务圆满完成。**

1. **任务难度与模型容量匹配：** 合成 4 高斯簇分类任务中，各簇分离度适中，属于相对简单的分类问题。中等容量 MLP（[64, 32]）足以充分拟合该决策边界，10 epochs 内即收敛到接近完美的准确率。

2. **收敛速度：** 在 AdamW + lr=1e-3 的配置下，模型快速收敛，最终 loss 降至 0.0188，说明优化过程稳定且高效。

3. **性能余量：** 0.9980 的准确率表明模型已接近该任务的理论上限（仅剩约 0.2% 的误差，可能来自簇边缘重叠样本）。这为后续调优提供了充足的性能余量——即使引入更复杂的正则化或数据增强，仍有较大空间保持达标。

4. **基线价值：** 该结果确立了强基线，后续任何改进（如更深的网络、正则化、数据增强）都需以不低于 0.9980 的准确率为基准进行对比。
