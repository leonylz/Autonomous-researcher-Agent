# 最终实验报告：Baseline MLP 在合成 4 高斯簇任务上的分类性能

**日期**：2025-04-17

## Summary

本实验验证了 baseline MLP（2-64-64-4）在合成 4 高斯簇分类任务上的性能。实验在 **10 epochs** 内达到 **test_acc = 0.999**，远超预设目标（**>= 0.90**），**目标已达成**。该结果证明一个中等容量的 MLP 足以在间距适中的 4 高斯簇任务上实现近乎完美的分类。

## 实验配置

| 配置项 | 值 |
|--------|-----|
| 框架 | PyTorch |
| 运行环境 | CPU |
| 模型 | MLP 2-64-64-4（ReLU 激活） |
| 数据 | 合成 4 高斯簇，2000 训练 / 2000 测试样本 |
| 优化器 | AdamW（lr=1e-3） |
| batch_size | 128 |
| Epochs | 10 |
| 随机种子 | 固定 seed |
| 评估指标 | 测试准确率（test_acc） |

## Results

| 实验 | 配置 | test_acc | loss | 目标 | 状态 |
|------|------|----------|------|------|------|
| Baseline MLP | 2-64-64-4, AdamW, 10 epochs, CPU | **0.999** | 0.012353 | >= 0.90 | ✅ 达成 |

## Analysis

- **性能表现**：最终测试准确率达到 **0.999**（99.9%），损失降至 **0.012353**，说明模型在 10 个 epoch 内已充分收敛。
- **目标达成**：0.999 显著高于 0.90 的目标阈值，超出预期约 10 个百分点。
- **任务难度**：合成 4 高斯簇任务中，各簇间距适中，类间可分性较好，因此中等容量 MLP 即可实现高精度分类。
- **配置合理性**：固定 seed 保证了实验可复现性；CPU 环境下 10 epochs 训练成本极低，验证了 baseline 的高效性。

## Next Steps

1. **压力测试**：缩小高斯簇间距或增加簇数，验证模型在更难任务上的泛化边界。
2. **模型对比**：引入更深/更宽的网络或不同优化器，对比 baseline 的性能与训练成本。
3. **鲁棒性验证**：在多个不同 seed 下重复实验，确认 0.999 结果的稳定性。
4. **扩展任务**：将 baseline 迁移到真实数据集，评估其在非合成数据上的表现。

---

**结论**：Baseline MLP（2-64-64-4）在合成 4 高斯簇任务上达到 test_acc=0.999，**目标（>=0.90）已达成**。
